# Kamino Research Corporation

**Independent AI lab, Singapore. Machines that build, research and remember.**

Kamino is an independent AI lab in Singapore building self-improving autonomous systems. Most systems still answer, forget, and wait. We build the other kind: systems that take a signal through to working results, keep what they learn, and spend it on the next pass.

Our emblem is an angel carrying a lantern and a key: find the light; open the door. Seek truth above comfort. Create with reverence. Build to endure.

---

## Build: [Hyperdrive](https://hyperdrive.kaminocorp.com)

An autonomous software engineering system. It runs the whole loop, from signal to shipped and monitored code, and does not stop at the pull request.

`signal → plan → build → deploy → monitor → repair`

Bring your own harness, or rent ours and skip the infrastructure. Run it on your cloud or ours. Open source is coming; today it is in private alpha, by invite.

[hyperdrive.kaminocorp.com](https://hyperdrive.kaminocorp.com) · [Docs](https://hyperdrive.kaminocorp.com/docs)

## Open infrastructure

Public primitives. Use them without us.

- **[Photon](https://github.com/kaminocorp/photon)**: visual perception pipeline in Rust. Images in; embeddings, tags, hashes, and metadata out. Runs locally.
- **[Parsec](https://github.com/kaminocorp/parsec)**: agent tooling for live system state: logs, databases, source.
- **[Lumber](https://github.com/kaminocorp/lumber)**: high-performance log normalization in Go. Raw provider logs into canonical events, on the machine.

Apache 2.0. Photon is dual MIT / Apache 2.0.

## Lab

Public work that is not a product. No availability implied.
